# Languages & Libraries

Design target: Trace's existing workspace and five-stage lesson flow. Reuse its type,
color roles, state colors, and accessible controls. Refero's live research was unavailable
in the preceding design pass; the existing product is the primary reference lock.

- Four language tracks, each split into foundations, collections, and ordering/search.
- Search plus one active lesson avoids a long nested sidebar.
- Real recorded values drive arrays and JSON views. No fabricated STL internals.
- Read-only references explain mutation, requirements, costs, and common mistakes.
- Separate example/exercise drafts preserve learner work. Grade only the exercise draft;
  record supported or independent evidence after all six cases pass.
- A reference panel beside existing workspaces keeps the active code in place.
- Cross-language comparison shares a goal, not an assumption of identical APIs.

Supported runtime versions: C++17, Python 3 portable APIs, Java 8, ES2022. ASCII strings
are used by the cross-language string exercises. JavaScript includes an explicit custom
min-heap because the language has no built-in standard PriorityQueue.
