# LinkedIn launch draft

I’m building **Trace**, a visual workspace for learning and teaching data structures and algorithms.

It has a 100-problem roadmap with editable Python, C++, Java and JavaScript examples. Learners can change inputs visually, follow recorded execution, add breakpoints and watches, investigate a failing case, and save their own code versions and revision notes.

I wanted something I could use while practising DSA myself: change a value, inspect what happens, and keep track of mistakes worth revisiting.

I’m now testing the learner experience and preparing the classroom connection for course assignments, teacher feedback and live prediction questions. I’d like feedback from DSA learners and online teachers before a small classroom pilot.
