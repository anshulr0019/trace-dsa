# Product roadmap

## Implemented for browser use

- Six foundations, a shared responsive workbench and the 100-problem roadmap.
- Editable references in Python, C++17, Java 8 and JavaScript, bounded execution and recorded playback.
- Visual input builders for arrays, strings, grids, compact trees and graph connections.
- Recorded source breakpoints, watches beside the source and stack-aware stepping where stack data exists.
- First-failing-case inspection and a verified reference replay for the same input.
- Custom problem variants, named code versions with restoration/undo, mistake journals and revision dates.
- Authored practice cases, progressive hints, predictions, beginner pace, notes and notebook backup/import.
- Local owner checks for all 100 problems across four languages and five check types, website workflow checks, run reports and role previews.
- Teacher lesson links, presentation mode, product tour, pitch deck and a LinkedIn launch draft.

## Implemented, requiring Supabase setup

- Email accounts, manual notebook transfer and opt-in automatic sync with conflict handling.
- Classes, assignments, enrollment moderation, class archiving, reusable ordered courses and written teacher feedback.
- Authenticated live classrooms with shared recorded execution, teacher playback, result reveal, prediction polls and response counts.
- Owner roles, shared quality checks, optional run-health metadata, published teaching explanations and revision history.

See [setup](TEACHER-SETUP.md). The connection and migrations must be applied before these cloud workflows can operate. No cloud behavior or test results are simulated.

## Owner acceptance testing

Use **Workspace checks** to record the actual evidence. Compiler/build checks establish buildability. Each animation, alignment, explanation, mobile or classroom check remains pending until someone performs and records it.

## After a classroom pilot

- Decide which teacher workflows justify a paid plan and connect billing after selecting a provider and business account.
- Add more authored approach comparisons and define operation counters consistently.
- Add authoritative judging before exams, competitive rankings or trusted grades.
- Consider grounded AI hints, collaborative editing, and account data deletion/retention tools.
- Record the launch demo after acceptance testing, then tailor the teacher pitch to the intended recipient.
