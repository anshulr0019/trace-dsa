# Trace: teacher and startup demo

[Download the editable six-slide pitch deck](Trace-Teacher-Pitch.pptx).

## One-minute introduction

Trace is a visual DSA learning workspace that connects code, recorded execution state and learner explanations. Its 100-problem roadmap covers 25 patterns, with editable Python, C++17, Java 8 and JavaScript references. A learner can change an input, follow the execution, predict a state change, write notes and practice a new case. A teacher can build a shareable example, use presentation mode and, once accounts are connected, assign it to a class and review student reflections and code.

## Six-slide presentation outline

1. **Trace — see the algorithm, explain the decision.** A code and visualization screenshot with the public demo link.
2. **Learning challenge.** Students can follow syntax but struggle to explain pointer movement, state changes and invariants. Describe the gap as the project's motivation; avoid unsupported outcome statistics.
3. **Learner workflow.** Explore → predict → inspect → explain → practice → revise. Show one coherent example.
4. **Teacher workflow.** Create a custom input and prompt → share → present → assign → review written reasoning and code.
5. **Engineering.** React/TypeScript, shared responsive workbench, disposable browser runtimes, bounded traces, editable references, and optional Supabase authentication/database with row access policies. Label browser scores as educational feedback.
6. **Pilot proposal.** One teacher, one DSA topic and a short pilot. Ask whether explanations became easier to discuss, which states remained confusing and how well it fits the teacher's workflow.
